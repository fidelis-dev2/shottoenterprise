# Shotto Enterprise Website

A responsive multi-page corporate website for Shotto Enterprise.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet access is required for the CDN libraries and Google Fonts.

## Pages
- index.html — Home
- about.html — About the company
- businesses.html — Business sectors
- projects.html — Projects and ventures
- news.html — News and updates
- contact.html — Contact form

## Brand assets
- `assets/images/logo.png` — supplied Shotto S mark
- `assets/images/cover.png` — supplied navy/green cover background

## Important before publishing
- Replace placeholder contact information with official company details.
- Add official social media URLs.
- The contact form currently validates in the browser and shows a SweetAlert confirmation only. It does not send or store messages until connected to a backend or email service.
- The business divisions are presented as areas of interest, not as claims that all divisions are already operating.
- Add real project images and verified announcements when available.

## Libraries (CDN)
Bootstrap 5.3.3, Bootstrap Icons, Font Awesome 6.7.2, SweetAlert2, AOS and Google Fonts.
No Node.js or frontend framework is required.
